# 실시간 웹캠 기반 생체 정보 분석 및 낙상 감지 시스템

본 프로젝트는 실시간 웹캠 피드를 활용하여 사용자의 거리에 따라 두 가지 모드(생체 정보 분석 / 낙상 감지)를 자동으로 전환하며 동작하는 하이브리드 비전 시스템입니다.

## 🚀 시작하기

### 1. 필수 라이브러리 설치

이 프로젝트는 `OpenCV`와 `MediaPipe`, `NumPy`를 사용합니다. 아래 명령어로 필요한 패키지를 설치하세요.

```bash
pip install opencv-python mediapipe numpy
```

### 2. 프로그램 실행

메인 스크립트를 실행하여 웹캠을 통한 모니터링을 시작합니다.

```bash
python main.py
```

- 프로그램을 종료하려면 영상 창이 활성화된 상태에서 영문 **`q`** 키를 누르세요.

## ⚙️ 시스템 구동 방식 (Execution Flow)
- 사전에 비교할 정상 상태일때의 사진을 찍어두어야 합니다. 이 사진을 통해 변화량을 비교합니다. 
1. **거리 판별 루프 (Main Loop):** 
   - 웹캠 프레임 입력 시 MediaPipe Face Detection을 통해 얼굴 영역(ROI) 바운딩 박스의 면적을 계산합니다.
2. **모드 스위칭:**
   - **원거리 (거리 임계치 미달):** `기능 2 (낙상 감지)` 실행
     - 사용자의 어깨, 골반, 무릎 좌표를 기반으로 서 있는지, 앉아 있는지, 낙상(누워 있는지)을 감지합니다.
   - **근거리 (거리 임계치 도달):** `기능 1 (생체 정보 분석)` 실행
     - 얼굴 영역의 색상 변화(녹색 채널)를 통해 심박수(rPPG)를 유추합니다.
     - HSV 색공간을 통해 붉은기(홍조)와 난반사 픽셀(발한) 변화량을 추적합니다.

## 📁 파일 구조

- `main.py`: 프로그램 진입점. 거리 판단 로직 및 모드 스위칭, 화면 렌더링을 담당합니다.
- `camera_manager.py`: 웹캠 입력을 처리하는 단순 래퍼 클래스입니다.
- `pose_detector.py`: MediaPipe Pose 모델을 사용하여 사용자 관절 좌표 기반 자세(낙상)를 판단합니다.
- `vital_analyzer.py`: MediaPipe Face Mesh를 사용하여 얼굴을 감지하고 기초적인 생체 신호(심박, 홍조, 땀)를 측정합니다.
